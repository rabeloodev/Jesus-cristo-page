# 📖 Landing Page - Jesus Cristo

Uma página web moderna, semântica e totalmente responsiva contendo ensinamentos, milagres e passagens bíblicas explicativas, enriquecida com animações fluidas baseadas em rolagem.

> 🌐 [**Acessar o Projeto Online**](https://rabeloodev.github.io/Jesus-cristo-page/)

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web nativas e uma das principais bibliotecas de animação do mercado:

*   **HTML5:** Estruturação puramente semântica (uso correto de `main`, `section`, `ol`, `ul` e `footer`).
*   **CSS3:** Estilização avançada com o uso de:
    *   **CSS Variables:** Controle centralizado da paleta de cores dos cards.
    *   **Flexbox & CSS Grid:** Alinhamento de containers verticais e distribuição de blocos em colunas simétricas.
*   **JavaScript & GSAP (GreenSock):** Integração com o plugin **ScrollTrigger** para gerenciar os gatilhos de animação na tela.

---

## 🎨 Funcionalidades em Destaque

*   **Animações Controladas por Scroll:** Os blocos de conteúdo e as citações surgem suavemente em formato de cascata (*stagger*) conforme entram na área visível da tela.
*   **Controle de Mídia Dinâmico (`matchMedia`):** Script estruturado inteligentemente para adaptar ou isolar comportamentos visuais complexos, garantindo uma navegação leve e confortável em qualquer dispositivo.
*   **Wrapper Controlador Geral (`.site-container`):** Arquitetura CSS limpa onde uma div mestre dita a largura e a centralização horizontal, tornando o layout escalável e livre de quebras.
